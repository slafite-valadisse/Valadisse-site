# Valadisse marketing site

Static site, deployed by Netlify when `main` changes. `index.html` holds Home,
Services, How It Works and Contact as one page; the blog is generated by
`node scripts/build-blog.mjs` (output is committed). The product lives in a
separate repo (app.valadisse.com); the claims here have to stay true to it.

## Claims

Rules, the same ones the pricing cards in the app follow:

- A claim may be stated as live only if it has shipped and a customer can use
  it today (a service delivered by hand counts, if it is being delivered).
- Anything not shipped carries a status pill with the same labels as the
  pricing cards: **Rolling out** (being released in stages, or delivered by
  hand while the automation is built) or **Coming soon** (in development, not
  available yet). The pill is `<span class="meta-pill status-pill" title="...">`.
- When a feature ships, update its row below and drop the pill in the same
  change. When a claim is removed, move it to "Removed" so it is not reinstated.
- Copy is in the third person, with no em dashes, no scoring formulas and no
  vendor names. Never "continuous", "around the clock", "unlimited" or "beta".
- `node scripts/check-claims.mjs` fails if a removed claim comes back.
